# Creative media system

George uses this provider-neutral area to plan visual and audio assets before
choosing production tooling. It contains briefs, rights/provenance requirements,
and evaluation criteria—no provider SDK, account, credential, API call, or paid
service.

## Think visually before choosing a tool

Start with: **What would make an HVAC professional stop scrolling and understand
this concept?** Select the production method only after defining the visual idea.

The website and PDFs are technical destinations, not default social templates.
Social work may share identity, typography, restrained color, or an end card, but
should not routinely resemble screenshots, PDF pages, generic panels, text slides,
or formula cards.

## Format rotation

Choose from short video/Reel, image carousel, one strong image plus technical
caption, original diagram, worked example, calculator demonstration, field-concept
visualization, cause/effect comparison, equipment explainer, misconception
explainer, quick tip, resource highlight, or an occasional interface capture when
the interface is the subject.

Do not rotate mechanically. Record why the format suits the concept, platform,
audience, recent content history, production effort, available assets, and any
future performance evidence from William. Actively avoid a repetitive feed.

## Visual vocabulary

Possible visual language includes:

- technicians or engineers in credible HVAC environments;
- rooftop units, air handlers, mechanical rooms, ductwork, VAV boxes, terminals,
  filter racks, fan and coil sections, dampers, and commercial distribution;
- conceptual airflow particles, streamlines, pressure fields, restrictions,
  transitions, filter loading, coil flow, fan operation, and component pressure
  drop;
- duct fly-throughs and cinematic mechanical environments;
- exploded AHU/RTU sections and subtle component movement; and
- cutaways of ducts, equipment, filters, fans, coils, dampers, or VAV boxes.

These are inspiration, not a finite menu. New concepts are encouraged.

## Technical visual safety

Never trade technical credibility for spectacle. Do not casually depict unsafe
electrical or rooftop behavior, missing materially relevant PPE, impossible
equipment arrangements as real, incorrect airflow direction or authoritative
component sequence, fake procedures, unrealistic instrument placement as
instruction, or unsupported diagnostics.

Use **CONCEPTUAL**, **ILLUSTRATIVE**, or **SIMPLIFIED** when exact realism is not
guaranteed. Every visual brief includes technical constraints, avoid conditions,
and required labels. A qualified technical check remains required before
publication approval.

## Directory boundary

- `media-brief.md`: provider-neutral scene specification
- `provider-evaluation.md`: criteria for future tools
- `provenance/`: persistent rights/provenance templates and guidance
- `prompts/`: persistent approved prompt/source notes when useful
- `growth/.generated/`: ignored disposable renders, exports, previews, and
  temporary media

No generated binary belongs in this directory.
