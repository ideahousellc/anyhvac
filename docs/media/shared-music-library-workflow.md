## Preparation workflow

1. George chooses music for the educational intent, pace and legibility of each
   authorized video. Alternate tracks when it improves the feed; do not force a
   rotation or alter an already approved publication automatically.
2. William verifies source identity against the registry, the exact recorded license,
   intended platform/use and saved proof before rendering/use. Changed files or
   uncertain licensing stop preparation. Recheck provider terms for new uses.
3. Record the selected source hash, excerpt, edits, measured audio checks, optional
   credit, video hash and media review version. Preserve any narration separately;
   never replace a mixed narration track without a suitable source stem.
4. Keep the approved revision and original assets unchanged. Use a separate local
   revision directory and append review history. William verifies only the allowed
   changes; the owner watches/listens and approves the exact new snapshot.
5. No library eligibility or agent signoff grants scheduling/publishing authority.
